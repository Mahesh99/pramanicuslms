Declaration versus Redirection
An asterisk operator can be used in two different contexts:For declaration and for redirection.Declaration: When an asterisk is used for declaration, it is associated with a type.For example, we define a pointer to an integer as			int *pa;			int *pb;Redirection: When used for redirection, the asterisk is an operator that redirects the operation from the pointer variable to a data variable.For example, given two pointers to integers, pa and pb, sum is computed as		int sum = *pa + *pb;
