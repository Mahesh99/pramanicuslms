# Advanced Excel course — design

## Goal

Add an **Advanced Excel** course to Pramanicus LMS, following the provided syllabus, with classroom notes, practice datasets, and the same seed path as Oracle SQL Training.

## Course

- **Title:** Advanced Excel
- **Slug:** `excel-training`
- **Description:** Hands-on Advanced Excel — functions, lookups, PivotTables, cleaning, formatting, charts, macros, validation, and basic statistics. Pramanicus Academy.
- **Running story:** Pramanicus Mart (India retail: Electronics, Fashion, Home & Kitchen; regions North, South, East, West). Same fictional chain as Power BI notes.

## Notes format

Match SQL modules so `parseModuleMarkdown` works:

- Opening `>` callouts for objectives and session info
- Section meta: emoji line, `Section X.Y`, then `## Heading`
- Formulas in fenced `excel` (or plain) code blocks
- Practice section labelled `Practice` before the exercises `##` heading
- Worked examples use real columns/values from the course datasets

## Modules (9)

| # | Slug | Title | Week | Syllabus |
|---|------|-------|------|----------|
| 1 | module1 | Basic functions | Week 1 | SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF |
| 2 | module2 | Lookup functions | Week 1 | VLOOKUP, HLOOKUP, XLOOKUP |
| 3 | module3 | Pivot tables | Week 1 | PivotTables, formatting, slicers |
| 4 | module4 | Data cleaning | Week 2 | Duplicates, sort/filter, LEFT/RIGHT/MID/CONCATENATE/TEXTJOIN |
| 5 | module5 | Conditional formatting | Week 2 | Colors, data bars, icon sets |
| 6 | module6 | Charts and graphs | Week 2 | Bar, line, pie, scatter |
| 7 | module7 | Macros | Week 3 | Record/run macros; light VBA |
| 8 | module8 | Data validation | Week 3 | Drop-downs, custom rules |
| 9 | module9 | Statistical analysis | Week 3 | STDEV, CORREL, Data Analysis ToolPak |

## Datasets

Downloadable from the app at `/excel/*.csv` (`public/excel/`). Regenerated by `scripts/generate-excel-datasets.mjs`.

| File | Purpose |
|------|---------|
| `regions.csv` | Dimension: RegionID, RegionName, Country, Manager |
| `products.csv` | Lookup table for VLOOKUP/XLOOKUP |
| `customers.csv` | Customer dimension |
| `sales.csv` | Fact transactions (Quantity, UnitPrice, Discount, Amount) |
| `quarterly_targets.csv` | Wide table for HLOOKUP (Q1–Q4 by ProductID) |
| `dirty_staff.csv` | Messy import for Module 4 |
| `practice_basics.csv` | Small 10-row sheet for Module 1 worked examples |

## LMS wiring

- Migration: insert course row (`on conflict do nothing`), same pattern as SQL/C
- `scripts/seed-excel-modules.mjs` + `npm run seed:excel`
- No schema/RLS changes; enrolled users already read `modules` by course

## Out of scope

- Excel Online live workbook hosting
- Macro-enabled `.xlsm` binaries in git (notes describe recording; no attack payloads)
- Power Query / Power Pivot (not on this syllabus)
- Module CRUD UI
