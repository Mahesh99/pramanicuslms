Section 3.1

Strings

What is a String?

A string is an ordered, immutable sequence of characters. Immutable means once created, individual characters cannot be changed — any string "modification" creates a brand-new string.

Indexing & Slicing

String indexing and slicing
s = "Hello, Python!"
#    0123456789...
#   -14 ... -1  (negative indices count from the right)

# Indexing — single character
print(s[0])      # 'H'     — first character
print(s[-1])     # '!'     — last character
print(s[7])      # 'P'

# Slicing — s[start:stop:step]
# stop is EXCLUDED
print(s[0:5])    # 'Hello'
print(s[7:])     # 'Python!'  — from index 7 to end
print(s[:5])     # 'Hello'    — from start to index 5
print(s[::2])    # every 2nd character
print(s[::-1])   # 'reverse the string!'
print(s[-7:-1]) # 'Python'

Common String Methods

String methods
s = "  Hello, World!  "

# Case
s.upper()         # "  HELLO, WORLD!  "
s.lower()         # "  hello, world!  "
s.title()         # "  Hello, World!  " (each word capitalised)
s.capitalize()    # "  hello, world!  " (only first char of string)

# Whitespace
s.strip()          # "Hello, World!"   — remove leading/trailing spaces
s.lstrip()         # "Hello, World!  " — left only
s.rstrip()         # "  Hello, World!" — right only

# Search
s.find("World")     # 9  — index of first occurrence (-1 if not found)
s.index("World")   # 9  — same but raises ValueError if not found
s.count("l")       # 3  — count occurrences
s.startswith("  H") # True
s.endswith("  ")   # True
"World" in s       # True  — membership test

# Modify (returns NEW string — strings are immutable)
s.replace("World", "Python")  # "  Hello, Python!  "
s.strip().replace(",", ";")   # chain methods

# Split and Join
"a,b,c".split(",")     # ['a', 'b', 'c']
"hello world".split() # ['hello', 'world']  — split on whitespace
", ".join(["Alice", "Bob", "Carol"]) # "Alice, Bob, Carol"

# Type check methods
"123".isdigit()    # True
"Hello".isalpha() # True
"abc123".isalnum()# True
"  ".isspace()    # True
💡
String methods don't change the original. Since strings are immutable, methods like .replace(), .upper(), .strip() always return a new string. To keep the result you must assign it: s = s.strip().

Section 3.2

Lists

What is a List?

A list is an ordered, mutable sequence that can hold items of any type (including other lists). It's the most versatile and most-used data structure in Python.

Creating lists
# Different ways to create a list
empty     = []
numbers   = [1, 2, 3, 4, 5]
mixed     = [1, "hello", 3.14, True]   # any types
from_range = list(range(1, 6))         # [1, 2, 3, 4, 5]
chars     = list("hello")              # ['h','e','l','l','o']

List Operations

List methods
fruits = ["apple", "banana", "cherry"]

# Adding items
fruits.append("date")          # add to end: [..., "date"]
fruits.insert(1, "avocado")   # insert at index 1
fruits.extend(["fig", "grape"]) # add multiple items
fruits += ["kiwi"]              # same as extend

# Removing items
fruits.remove("banana")        # remove first occurrence by value
popped = fruits.pop()         # remove and return last item
popped = fruits.pop(0)       # remove and return item at index 0
del fruits[1]                  # delete by index
fruits.clear()                 # remove all items

# Searching
fruits.index("cherry")         # first index of value
fruits.count("apple")         # count occurrences
"mango" in fruits              # True/False membership

# Sorting
nums = [3, 1, 4, 1, 5, 9]
nums.sort()                    # sort in place, ascending
nums.sort(reverse=True)        # sort descending
sorted_nums = sorted(nums)    # returns NEW sorted list (original unchanged)
nums.reverse()                 # reverse in place

# Other
len(fruits)                    # number of items
fruits.copy()                  # shallow copy
fruits2 = fruits[:]            # another way to copy via slice

List Comprehensions

A list comprehension is a concise, readable way to create a list from another iterable. It is typically faster than a regular for loop.

List comprehensions
# Syntax: [expression for item in iterable if condition]

# Without comprehension:
squares = []
for x in range(1, 6):
    squares.append(x**2)

# With comprehension:
squares = [x**2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]

# With a condition (filter):
evens = [x for x in range(20) if x % 2 == 0]

# With transformation and condition:
upper_long = [w.upper() for w in words if len(w) > 3]

# Nested comprehension (2D matrix):
matrix = [[i * j for j in range(1, 4)] for i in range(1, 4)]
# [[1,2,3],[2,4,6],[3,6,9]]

# Flatten a 2D list:
flat = [item for row in matrix for item in row]

Section 3.3

Tuples

What is a Tuple?

A tuple is an ordered, immutable sequence. Once created, you cannot add, remove, or change items. Use tuples for data that should not change — coordinates, RGB colours, database rows, function return values.

Tuples
# Creating tuples
point  = (10, 20)
rgb    = (255, 128, 0)
single = (42,)          # MUST have trailing comma for single-item tuple
empty  = ()

# Indexing and slicing (same as list)
print(point[0])          # 10
print(rgb[-1])           # 0

# Packing and Unpacking
coordinates = (35.6, 139.7)      # packing
latitude, longitude = coordinates  # unpacking
print(latitude)   # 35.6

# Starred unpacking
first, *rest = (1, 2, 3, 4, 5)
print(first)   # 1
print(rest)    # [2, 3, 4, 5]

# Swap variables (tuple packing/unpacking under the hood)
a, b = 10, 20
a, b = b, a
print(a, b)    # 20, 10

# Immutability
point[0] = 99   # TypeError: 'tuple' object does not support item assignment

Why Use Tuples Instead of Lists?

  • Tuples signal intent — "this data should not change"
  • Tuples are slightly faster and use less memory than lists
  • Tuples can be used as dictionary keys (lists cannot, because lists are mutable)
  • Functions often return multiple values as a tuple: return x, y

Section 3.4

Sets

What is a Set?

A set is an unordered collection of unique elements. It automatically removes duplicates. Sets support fast membership testing (in) and mathematical set operations (union, intersection, etc.).

Sets
# Creating sets
fruits = {"apple", "banana", "cherry"}
nums   = {1, 2, 3, 2, 1}   # → {1, 2, 3}  duplicates removed
empty  = set()              # empty set — NOT {} (that's an empty dict!)

# Add and remove
fruits.add("mango")
fruits.discard("apple")    # no error if not present
fruits.remove("banana")   # KeyError if not present

# Membership (O(1) — very fast)
print("cherry" in fruits)  # True

# ─── Set Operations ───────────────────────────────────────────
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

# Union — all elements from both sets
print(a | b)          # {1, 2, 3, 4, 5, 6}
print(a.union(b))

# Intersection — elements in both
print(a & b)          # {3, 4}
print(a.intersection(b))

# Difference — in a but not in b
print(a - b)          # {1, 2}
print(a.difference(b))

# Symmetric difference — in either but not both
print(a ^ b)          # {1, 2, 5, 6}

# Subset / superset checks
print({1,2} <= a)    # True  — {1,2} is a subset of a
print(a >= {1,2})   # True  — a is a superset of {1,2}

Practical Use — Remove Duplicates from a List

De-duplicate a list
data = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]
unique = list(set(data))   # fast de-duplication (order not preserved)
print(unique)
⚠️
Sets are unordered. There is no guaranteed order of elements. Do not rely on iteration order. If you need unique elements with order, use dict.fromkeys(data) (Python 3.7+).

Section 3.5

Dictionaries

What is a Dictionary?

A dictionary is a mutable, ordered collection of key-value pairs. Keys must be unique and hashable (strings, numbers, tuples). Think of it like a real dictionary — you look up a key (word) to get its value (definition).

Since Python 3.7, dictionaries maintain insertion order.

Dictionary basics
# Creating a dictionary
student = {
    "name":  "Riya Sharma",
    "age":   20,
    "grade": "A",
    "score": 92.5
}

# Reading values
print(student["name"])           # "Riya Sharma"
print(student.get("age"))        # 20
print(student.get("city", "N/A")) # "N/A" — default if key missing
# student["city"]  ← KeyError if key doesn't exist — use .get() to be safe

# Adding / updating
student["city"]  = "Hyderabad"   # add new key
student["score"] = 95.0          # update existing key
student.update({"phone": "9876543210", "grade": "A+"})

# Removing
del student["phone"]             # KeyError if not present
student.pop("city")              # removes and returns the value
student.pop("missing", None)    # safe pop with default
student.clear()                  # remove everything

Iterating Over Dictionaries

Iterating dictionaries
student = {"name": "Riya", "age": 20, "grade": "A"}

# Keys only (default)
for key in student:
    print(key)

# Values only
for value in student.values():
    print(value)

# Key and value together — most common
for key, value in student.items():
    print(f"{key}: {value}")

# Check if a key exists
if "grade" in student:
    print("Grade is:", student["grade"])

Dictionary Comprehensions

Dict comprehensions
# {key_expr: value_expr for item in iterable if condition}

squares = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filter: only students who passed
scores  = {"Alice": 88, "Bob": 45, "Carol": 72}
passing = {name: score for name, score in scores.items() if score >= 50}

# Invert a dict (swap keys and values)
inverted = {v: k for k, v in scores.items()}

Section 3.6

Nested Data Structures

List of Dictionaries — Tabular Data

List of dicts — student records
students = [
    {"name": "Alice", "age": 20, "score": 88},
    {"name": "Bob",   "age": 22, "score": 72},
    {"name": "Carol", "age": 21, "score": 95},
]

# Access: list index, then dict key
print(students[0]["name"])   # "Alice"

# Loop through all students
for s in students:
    print(f"{s['name']}: {s['score']}")

# Sort by score descending
students.sort(key=lambda s: s["score"], reverse=True)

# Filter: only students with score >= 80
top_students = [s for s in students if s["score"] >= 80]

Dictionary of Lists — Grouped Data

Dict of lists — timetable
timetable = {
    "Monday":    ["Python", "Mathematics"],
    "Tuesday":   ["Physics", "English"],
    "Wednesday": ["Python", "Chemistry"],
}

# Access
print(timetable["Monday"][0])   # "Python"

# Add a class to a day
timetable["Monday"].append("Lab")

# Loop
for day, subjects in timetable.items():
    print(f"{day}: {', '.join(subjects)}")

Section 3.7

Choosing the Right Data Structure

If you need…UseWhy
An ordered, changeable collectionlistMost general-purpose container
Fixed data that shouldn't changetupleImmutability, can be dict key, slightly faster
Unique items + fast membership testsetO(1) lookup, automatic deduplication
Key → value lookupdictO(1) access by key
Counting occurrencescollections.CounterSpecialised dict subclass
Dict with automatic default valuescollections.defaultdictNo KeyError for missing keys
Sequence of textstrRich set of string methods
💡
Mental checklist: Is order important? Is it fixed/mutable? Do I need duplicates? Do I look up by position or by name? Answering these questions points you to the right type.
