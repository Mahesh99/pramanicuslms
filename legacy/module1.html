Section 1.1

Introduction to Python

What is Python?

Python is a high-level, general-purpose, interpreted programming language. "High-level" means it reads more like English than machine code. "Interpreted" means code is executed line by line — you don't need to compile it into a separate program before running it.

Python was created by Guido van Rossum and first released in 1991. The name comes from the BBC comedy show Monty Python's Flying Circus, not from the snake — though the snake is now the logo!

Why Learn Python?

  • Readable syntax — code looks almost like plain English, so it's easy to learn and maintain.
  • Versatile — used for web development, data science, AI/ML, automation, scripting, desktop apps, and more.
  • Huge ecosystem — hundreds of thousands of free libraries available via pip.
  • Most in-demand skill — consistently ranks #1 or #2 in programming language popularity surveys.
  • "Batteries included" — Python's standard library handles file I/O, web requests, math, dates, and much more without installing anything extra.

Python 2 vs Python 3

The Python Philosophy

Python has a design philosophy written by Tim Peters called The Zen of Python. Run import this in the Python shell to read it. Key ideas:

✅ Beautiful is better than ugly

Write code that other people can read and understand easily.

✅ Simple is better than complex

If a simple solution works, use it. Avoid over-engineering.

✅ Readability counts

Code is read far more often than it is written.

✅ There should be one obvious way

Python aims for one clear, idiomatic way to solve a problem.

Installation & IDEs

Installing Python

  1. Go to python.org → Downloads → Download the latest Python 3.x installer
  2. Run the installer. On Windows: tick "Add Python to PATH" before clicking Install
  3. Open a terminal (Command Prompt / PowerShell / Terminal) and verify:

Choosing an IDE / Editor

An IDE (Integrated Development Environment) is software that helps you write, run, and debug code. You need at least a good text editor.

🆚 VS Code (recommended for beginners)
Free, lightweight, highly customisable. Install the Python extension by Microsoft and Pylance for type hints. Best for small to medium projects and beginners.
🧠 PyCharm Community Edition
Free, purpose-built for Python. Has the most powerful debugger, code refactoring tools, and built-in support for virtual environments. Best for large projects.
📓 Jupyter Notebook / JupyterLab
Runs in your browser. Code is written in "cells" — you can run individual cells without rerunning the whole file. Ideal for data analysis, visualisation, and teaching/learning.

Section 1.3

Running Python Code

Method 1: Interactive Shell (REPL)

REPL stands for Read–Evaluate–Print–Loop. Open a terminal and type python or python3. You get a >>> prompt where you type one line at a time and see the result immediately. Great for experimenting.

Interactive Shell
$ python
Python 3.12.0 (...)
>>> 2 + 3
5
>>> print("Hello, World!")
Hello, World!
>>> exit()    # or press Ctrl+D / Ctrl+Z

Method 2: Running a Script File

Write your code in a file with the .py extension, then run it from the terminal. This is how real programs work.

hello.py
print("Hello, World!")
print("Welcome to Python!")
Terminal
python hello.py
Hello, World!
Welcome to Python!
ℹ️
REPL vs Script — when to use which? Use the REPL for quick experiments, testing an expression, or exploring a module. Use script files for anything you want to save, share, or run again.

Section 1.4

Variables

What is a Variable?

Think of a variable as a labelled box. You put a value inside the box and give it a name so you can refer to that value later. Unlike most other languages, Python variables don't need to declare their type upfront — Python figures it out automatically.

Creating variables
name  = "Alice"          # the box named 'name' holds the text "Alice"
age   = 20              # the box named 'age' holds the number 20
score = 95.5            # a decimal number
passed = True           # a True/False value

# You can reassign — the box gets a new value
age = 21
print(age)   # 21

Multiple Assignment

Multiple assignment shortcuts
# Assign multiple variables in one line
x, y, z = 1, 2, 3

# Assign same value to multiple variables
a = b = c = 0

# Swap two variables (Python-style — no temp variable needed)
x, y = y, x
💡
Python's variable model — names, not boxes Technically, Python variables are names that point to objects in memory. When you write x = 5, Python creates the integer object 5 in memory and makes the name x point to it. This matters because two names can point to the same object: a = b = [1,2,3] — both a and b point to the same list.

Core Data Types

Overview

A data type tells Python what kind of value is stored in a variable — a number, text, True/False, etc. Python is dynamically typed: you don't declare the type; Python determines it when the program runs.

TypeKeywordExample ValuesDescription
Integerint0, 42, -7, 1_000_000Whole numbers, no decimal point. Unlimited size in Python 3.
Floatfloat3.14, -0.5, 1.0e10Numbers with a decimal point (IEEE 754 64-bit).
Stringstr"hello", 'Alice'Sequence of text characters. Immutable.
BooleanboolTrue, FalseLogical true/false. Subtype of int (True=1, False=0).
Complexcomplex3 + 4j, 1jReal + imaginary parts. Used in engineering/science.
NoneNoneTypeNoneRepresents "nothing" or "no value". Like null in other languages.

Integers (int)

Integers
x = 42
y = -7

binary = 0b1010      # binary literal → 10
octal  = 0o17        # octal literal  → 15

print(type(x))      # <class 'int'>

Floats (float)

Floats
pi    = 3.14159
small = 1.5e-4     # scientific notation: 0.00015
big   = 2.5e6      # 2500000.0

# Float precision issue — important to know!
print(0.1 + 0.2)   # 0.30000000000000004  ← not exactly 0.3!

# Use the 'decimal' module when precision matters (e.g. money).
⚠️
Float precision is not exact 0.1 + 0.2 gives 0.30000000000000004 in Python (and in most programming languages). This is a property of IEEE 754 binary floating point, not a Python bug. For financial calculations, use from decimal import Decimal.

The type() and id() Functions

type() and id()

Section 1.6

Type Casting & Type Checking

What is Type Casting?

Converting a value from one type to another. Python does some conversions automatically (implicit casting), but usually you need to do it yourself (explicit casting).

Explicit Type Casting

Type conversion functions
# int() — convert to integer
int("42")        # 42      — string to int
int(3.9)        # 3       — float to int (truncates, does NOT round)
int(True)       # 1
int(False)      # 0

# float() — convert to float
float("3.14")   # 3.14
float(5)        # 5.0

# str() — convert to string
str(42)         # "42"
str(3.14)       # "3.14"
str(True)       # "True"

# bool() — convert to boolean
bool(0)         # False  — zero is falsy
bool(42)        # True   — any non-zero number is truthy
bool("")        # False  — empty string is falsy
bool("hello")   # True   — non-empty string is truthy
bool(None)      # False

Common Pitfall: Converting Strings to Numbers

Common casting mistakes
# ✅ This works:
int("42")           # 42

# ❌ This raises ValueError:
int("3.14")         # ValueError: invalid literal for int()

# ✅ Correct way to convert "3.14" to int:
int(float("3.14"))  # 3  (first convert to float, then to int)

# Common in programs that read user input:
age = int(input("Enter your age: "))   # input() always returns str

Type Checking with isinstance()

isinstance() vs type()
x = 42

# isinstance() — preferred (works with inheritance)
isinstance(x, int)           # True
isinstance(x, (int, float))  # True — check against multiple types
isinstance(True, int)        # True — because bool is a subclass of int

# type() exact match — does not account for subclasses
type(x) == int               # True
type(True) == int             # False! True is a bool, not exactly int
type(True) == bool            # True
✅
Best Practice: Prefer isinstance() over type() == for type checking in most situations.

Section 1.7

Operators

Arithmetic Operators

Arithmetic
a, b = 17, 5

print(a + b)    # 22   — addition
print(a - b)    # 12   — subtraction
print(a * b)    # 85   — multiplication
print(a / b)    # 3.4  — division (ALWAYS returns float)
print(a // b)   # 3    — floor division (integer division, rounds DOWN)
print(a % b)    # 2    — modulo (remainder)
print(a ** b)   # 1419857 — exponentiation (17 to the power 5)

# Useful patterns with % (modulo)
# Check if a number is even:
print(8 % 2 == 0)  # True
# Get last digit of a number:
print(12345 % 10)  # 5

Comparison Operators

These always return True or False.

Comparison
x, y = 10, 20
print(x == y)   # False — equal to
print(x != y)   # True  — not equal to
print(x <  y)   # True  — less than
print(x >  y)   # False — greater than
print(x <= y)   # True  — less than or equal
print(x >= y)   # False — greater than or equal

# Python allows chained comparisons (very useful!)
age = 25
print(18 <= age < 60)  # True — reads like maths

Logical Operators

Logical operators
# and — both conditions must be True
print(True  and True)   # True
print(True  and False)  # False

# or — at least one condition must be True
print(False or  True)   # True
print(False or  False)  # False

# not — reverses the boolean
print(not True)          # False
print(not False)         # True

# Short-circuit evaluation:
# 'and' stops at first False value
# 'or'  stops at first True value
x = 0
print(x and 10/0)  # 0 — division never evaluated (x is falsy)

Assignment Operators

Assignment operators
x = 10
x += 3    # x = x + 3  → 13
x -= 2    # x = x - 2  → 11
x *= 4    # x = x * 4  → 44
x //= 3   # x = x // 3 → 14
x %= 5    # x = x % 5  → 4
x **= 2   # x = x ** 2 → 16

Identity & Membership Operators

is, in operators
# Identity: is / is not  — same object in memory?
a = [1, 2]
b = [1, 2]
c = a
print(a == b)    # True  — same values
print(a is b)   # False — different objects in memory
print(a is c)   # True  — c points to same object as a
print(x is None)  # idiomatic way to check for None

# Membership: in / not in  — is item inside a collection?
fruits = ["apple", "banana", "cherry"]
print("banana" in fruits)      # True
print("mango"  not in fruits)  # True
print("lo" in "Hello")         # True — works in strings too

Operator Precedence

Python evaluates operators in this order (highest to lowest), just like BODMAS/PEMDAS in maths:

PriorityOperator(s)Description
1 (highest)**Exponentiation
2+x, -x, ~xUnary +/−, bitwise NOT
3*, /, //, %Multiply, divide, floor div, modulo
4+, -Add, subtract
5<<, >>Bitwise shift
6&, ^, |Bitwise AND, XOR, OR
7==, !=, <, >, <=, >=, is, inComparisons
8notLogical NOT
9andLogical AND
10 (lowest)orLogical OR
💡
Use parentheses to be explicit. Even when precedence rules would give the right answer, parentheses make your code easier to read: (a + b) * c is clearer than relying on the reader to remember precedence.

Input & Output

The print() Function

print() options
# Basic print
print("Hello, World!")

# Multiple values — separated by space by default
print("Name:", "Alice", "Age:", 20)
# Output: Name: Alice Age: 20

# Output: Loading...done

The input() Function

input()
# input() always returns a STRING
name = input("Enter your name: ")
print("Hello,", name)

# Must cast to int/float if you need a number
age = int(input("Enter your age: "))

price = float(input("Enter price: "))
❌
Common beginner mistake age = input("Enter age: ") then age + 10 will raise a TypeError because you're trying to add a string and an integer. Always cast input() to the appropriate type.

Section 1.9

String Formatting

String formatting lets you embed values inside strings. There are three main methods. f-strings are the modern, recommended approach.

Method 1: f-Strings (Python 3.6+) — Recommended

f-strings
name  = "Arjun"
score = 95.5
grade = "A"

# Basic f-string — prefix with f, embed variables in {}
print(f"Student: {name}, Score: {score}")
# Student: Arjun, Score: 95.5

# Format specifiers inside {}
print(f"Score: {score:.2f}")      # 2 decimal places: 95.50
print(f"Score: {score:8.2f}")     # width 8, 2 decimals:    95.50
print(f"Name: {name:<10}|")       # left-align in 10 chars: Arjun     |
print(f"Name: {name:>10}|")       # right-align:            Arjun|
print(f"Name: {name:^10}|")       # center-align:     Arjun     |

# Expressions inside {}  
print(f"2 + 2 = {2+2}")
print(f"Upper: {name.upper()}")

# Debugging with f"{var=}" (Python 3.8+)
x = 42
print(f"{x=}")   # x=42

Method 2: .format()

.format() method
# Positional
print("Hello, {}! You scored {:.1f}.".format(name, score))

# Named
print("Hello, {n}! Score: {s:.1f}".format(n=name, s=score))

# Indexed
print("{0} got {1:.1f} in {0}'s exam".format(name, score))

Method 3: % Formatting (Legacy)

% formatting (older style)
print("Hello, %s! Score: %.1f" % (name, score))
# %s = string, %d = integer, %f = float, %.2f = float with 2 decimals
✅
Use f-strings. They are faster, more readable, and support any Python expression inside {}. Use .format() when you need to store the template as a variable. Avoid % formatting in new code.

Section 1.10

Comments & Docstrings

Comments

Comments are notes for humans — Python ignores them completely. Use them to explain why code does something, not what it does (the code itself shows what).

Types of comments
# Single-line comment — starts with #
x = 42  # inline comment — use sparingly

# Multiple lines — just use multiple # lines
# Python has no /* */ block comment syntax.
# Each line starts with #

# ❌ Bad comment — just restates the code:
x = x + 1  # add 1 to x

# ✅ Good comment — explains WHY:
x = x + 1  # account for 0-based index offset

Docstrings

A docstring is a special string placed immediately after a def or class statement. It documents what a function/class does and is accessible at runtime via .__doc__ or help().

Writing docstrings
def calculate_grade(score):
    """
    Return the letter grade for a given numeric score.

    Args:
        score (float): Numeric score between 0 and 100.

    Returns:
        str: Letter grade — 'A', 'B', 'C', 'D', or 'F'.

    Examples:
        >>> calculate_grade(92)
        'A'
        >>> calculate_grade(55)
        'F'
    """
    if   score >= 90: return "A"
    elif score >= 75: return "B"
    elif score >= 60: return "C"
    elif score >= 40: return "D"
    else:            return "F"

# Access the docstring
print(calculate_grade.__doc__)
help(calculate_grade)

Indentation & PEP 8

Indentation is Mandatory in Python

Most languages use {} to group code. Python uses indentation (spaces at the start of a line). This enforces readability. The standard is 4 spaces per level — never use tabs.

Indentation
if True:
    print("indented 4 spaces — this is inside the if block")
    if True:
        print("indented 8 spaces — nested block")
print("back to no indent — outside the if block")

# ❌ Wrong — mixing spaces and tabs, or inconsistent spacing
# will raise an IndentationError

Key PEP 8 Rules

PEP 8 is Python's official style guide. Following it makes your code readable by any Python developer.

No spaces inside bracketsfunc(a, b)func( a, b )
Variable names in snake_casestudent_namestudentName, StudentName
Class names in PascalCaseStudentRecordstudent_record
