Section 2.1

What is Control Flow?

By default, Python runs your code line by line from top to bottom. Control flow lets you change that — making the program branch (run different code based on a condition) or repeat (run the same code multiple times).

🔀 Branching

Execute different blocks of code based on a condition. "If the score is ≥ 90, print A. Otherwise, print B."

🔁 Looping

Execute a block of code repeatedly. "Print all numbers from 1 to 100." or "Keep asking for input until the user types 'quit'."

Section 2.2

if / elif / else

Basic Structure

if / elif / else syntax
if condition:
    # runs if condition is True
elif another_condition:
    # runs if first is False AND this is True
else:
    # runs if ALL conditions above were False

Grade Classification Example

Grade calculator
score = float(input("Enter your score (0-100): "))

if score >= 90:
    grade = "A"
    message = "Excellent!"
elif score >= 75:
    grade = "B"
    message = "Good work!"
elif score >= "C"
    message = "Satisfactory"
elif score >= 40:
    grade = "D"
    message = "Needs improvement"
else:
    grade = "F"
    message = "Please attend remedial classes"

print(f"Grade: {grade} — {message}")

Important Rules

  • Every if block must end with a colon :
  • The code inside the block must be indented (4 spaces)
  • elif and else are optional — you can have just an if
  • You can have as many elif clauses as you need
  • Only the first matching branch executes — once a condition is True, the rest are skipped

Nested if Statements

Nested conditions
age    = int(input("Age: "))
has_id = input("Do you have a valid ID? (yes/no): ") == "yes"

if age >= 18:
    if has_id:
        print("Entry allowed")
    else:
        print("Please bring a valid ID")
else:
    print("Sorry, must be 18+")

# The same logic using 'and':
if age >= 18 and has_id:
    print("Entry allowed")
💡
Flatten nested ifs when possible. Deeply nested conditions become hard to read. Use and/or to combine conditions, or use early return in functions (covered in Module 4).

Section 2.3

Truthiness & Falsy Values

In Python, any value can be used as a condition in an if statement. Python converts it to True or False automatically. Knowing which values are "falsy" is essential.

Falsy Values — Evaluate to False

ValueTypeMeaning
FalseboolThe literal False
NoneNoneTypeNo value
0intZero integer
0.0floatZero float
""strEmpty string
[]listEmpty list
()tupleEmpty tuple
{}dict / setEmpty dict or set

Everything else is truthy — non-zero numbers, non-empty strings, non-empty lists, etc.

Truthiness in practice
name = input("Enter your name: ")

# Pythonic way to check for empty input:
if name:             # True if name is not empty
    print(f"Hello, {name}!")
else:
    print("No name provided.")

# Check if a list has items:
items = []
if not items:
    print("The list is empty")

# Check for None:
value = None
if value is None:      # preferred over 'if not value' for None checks
    print("No value")

Section 2.4

for Loops

What is a for Loop?

A for loop iterates over a sequence — it goes through each item one by one. You can loop over lists, strings, tuples, ranges, dictionaries, and anything else that is iterable.

for loop syntax
for variable in iterable:
    # body — runs once for each item

Looping Over Common Types

for loop examples
# Loop over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# Loop over a string (each character)
for char in "Hello":
    print(char)
# Prints: H e l l o (each on a new line)

# Loop a specific number of times with range()
for i in range(5):       # i = 0, 1, 2, 3, 4
    print(f"Iteration {i}")

# Loop over a dictionary
student = {"name": "Riya", "age": 20, "grade": "A"}
for key, value in student.items():
    print(f"{key}: {value}")

for / else

Python's for loop has an optional else clause that runs only if the loop completed without hitting a break. This is unusual but very useful for search patterns.

for/else — search pattern
numbers = [3, 7, 11, 15, 20]
target = 11

for n in numbers:
    if n == target:
        print(f"Found {target}!")
        break
else:
    print(f"{target} not found in the list")
# The else only runs if 'break' was never hit

Section 2.5

while Loops

What is a while Loop?

A while loop runs as long as a condition is True. Use it when you don't know in advance how many iterations you'll need.

while loop examples
# Basic countdown
count = 5
while count > 0:
    print(count)
    count -= 1    # MUST update the condition variable, or infinite loop!
print("Go!")

# Input validation — repeat until valid input
while True:
    age = input("Enter your age (1-120): ")
    if age.isdigit() and 1 <= int(age) <= 120:
        age = int(age)
        break           # valid input — exit the loop
    print("Invalid. Please try again.")
print(f"Your age is: {age}")

# Guessing game
secret = 42
attempts = 0

while True:
    guess = int(input("Guess the number (1-100): "))
    attempts += 1
    if   guess < secret: print("Too low!")
    elif guess > secret: print("Too high!")
    else:
        print(f"Correct! You got it in {attempts} attempts.")
        break
🚨
Infinite Loop If you forget to update the condition variable (or never reach a break), your program will run forever. Press Ctrl+C to stop it. Always double-check that your while loop has a path to termination.

for vs while — When to Use Which

Use for when…Use while when…
You know how many iterations in advanceYou don't know how many iterations you need
You're iterating over a collectionYou're waiting for a condition to change
for i in range(10)Input validation, game loops, network retry

Section 2.6

break / continue / pass

StatementEffectAnalogy
breakExit the loop immediatelyEmergency exit — leave the room entirely
continueSkip rest of this iteration; go to nextSkip this item; move to the next one in line
passDo nothing — a placeholderEmpty box — "I'll fill this in later"
break, continue, pass examples
# break — stop the loop early
for i in range(10):
    if i == 5:
        break           # stop when we hit 5
    print(i)            # prints 0 1 2 3 4

# continue — skip even numbers
for i in range(1, 11):
    if i % 2 == 0:
        continue        # skip even numbers
    print(i)            # prints 1 3 5 7 9

# pass — empty block placeholder
for i in range(5):
    pass               # loop does nothing — useful while developing

# pass in an if block (when you haven't coded the body yet)
if some_condition:
    pass               # TODO: implement this
else:
    print("doing something")

# Combined example — process valid items, stop on sentinel
data = [3, 7, -1, 5, 2]   # -1 signals end of data
total = 0
for n in data:
    if n == -1:
        break           # stop at sentinel
    if n < 0:
        continue        # skip other negatives
    total += n
print(f"Total: {total}")   # 10

Section 2.7

Nested Loops

A loop inside another loop is called a nested loop. The inner loop runs completely for every single iteration of the outer loop.

Nested loop — multiplication table
# Multiplication table (1 to 5)
for i in range(1, 6):          # outer loop: rows
    for j in range(1, 6):      # inner loop: columns
        print(f"{i*j:4}", end="")
    print()                    # newline after each row
Pattern printing — right triangle
n = 5

# Right triangle of *
for i in range(1, n + 1):
    print("* " * i)
# *
# * *
# * * *
# * * * *
# * * * * *

# Pyramid
for i in range(1, n + 1):
    print(" " * (n - i) + "* " * i)
⚠️
Performance note. If your outer loop runs 1,000 times and your inner loop runs 1,000 times, the body executes 1,000,000 times. Avoid deeply nested loops on large data — they can be very slow.

Section 2.8

range(), enumerate(), zip()

range() — Generate a Sequence of Numbers

range()
# range(stop)           → 0 to stop-1
# range(start, stop)    → start to stop-1
# range(start,stop,step)→ with custom step

list(range(5))           # [0, 1, 2, 3, 4]
list(range(1, 6))        # [1, 2, 3, 4, 5]
list(range(0, 10, 2))    # [0, 2, 4, 6, 8]  — even numbers
list(range(10, 0, -1))   # [10, 9, 8 ... 1] — countdown

# Practical use: sum of first N natural numbers
total = 0
for i in range(1, 101):   # 1 to 100
    total += i
print(total)   # 5050

enumerate() — Index + Value Together

When you need both the position and the value of each item, use enumerate() instead of managing a counter manually.

enumerate()
students = ["Alice", "Bob", "Carol", "Dave"]

# Without enumerate — manual counter
i = 0
for name in students:
    print(i, name)
    i += 1

# With enumerate — cleaner
for i, name in enumerate(students):
    print(f"{i}. {name}")

# Start index from 1 instead of 0
for i, name in enumerate(students, start=1):
    print(f"{i}. {name}")
# 1. Alice
# 2. Bob
# 3. Carol
# 4. Dave

zip() — Pair Elements from Multiple Iterables

zip()
names  = ["Alice", "Bob", "Carol"]
scores = [88, 92, 75]
grades = ["B", "A", "C"]

# zip two lists
for name, score in zip(names, scores):
    print(f"{name}: {score}")

# zip three lists
for name, score, grade in zip(names, scores, grades):
    print(f"{name} — {score} ({grade})")

# zip stops at the shortest iterable
# To pad instead, use itertools.zip_longest

# Unzipping — convert list of pairs back to two lists
pairs = [("Alice", 88), ("Bob", 92)]
names, scores = zip(*pairs)
print(names)   # ('Alice', 'Bob')

Section 2.9

Ternary (Conditional) Expressions

A ternary expression is a one-line shorthand for an if/else that evaluates to a value.

Ternary syntax
# Syntax: value_if_true if condition else value_if_false

# Long form:
if score >= 50:
    result = "Pass"
else:
    result = "Fail"

# Ternary equivalent:
result = "Pass" if score >= 50 else "Fail"

# More examples
parity = "even" if n % 2 == 0 else "odd"
label  = "adult" if age >= 18 else "minor"

# Use in a print statement
print(f"{name} is an {'adult' if age >= 18 else 'minor'}")
⚠️
Don't nest ternaries. a if c1 else b if c2 else c is hard to read. If you need multi-branch logic, use a proper if/elif/else block instead.
